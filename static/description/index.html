HR Contract Document Management

Automated Employment Contract Document Workflow
for Odoo HR & Contracts.

💡 Overview

This add‑on extends Odoo’s core hr_contract module with a professional document management system for employment contracts. It provides structured templates, modular text snippets, version tracking, and dynamic PDF generation directly from the employee record.

✨ Key Features

  • Dynamic Contract Templates with placeholders like ${employee_name} or ${contract_wage}
  • Editable Snippets as reusable text blocks validated against template placeholders
  • Attachments – manage company and language‑specific documents
  • Configurable Signer Rules (e.g., HR Manager, Supervisor)
  • Wizard for Interactive PDF Generation
  • Rich Access Control: HR User, Specialist, Admin & Signer roles
  • Multi‑company support and audit‑ready design
  • Integrated QWeb report for printable contract documents

🧑‍💼 Who Is It For?

Designed for HR departments, legal teams, and organizations that require efficient, secure, and automated workflow for contract generation and record keeping.

🖼️ Example Screens

All views and reports are fully customizable to match your company branding.

🚀 Technical Info

  • Supported Versions: Odoo 18 Community & Enterprise
  • Requirements: Python 3.11+, PostgreSQL 15+
  • Depends on: hr_contract, mail, web
  • License: LGPL‑v3 (Open Source, Commercial Friendly)

🔒 Security & Roles

  • HR User: Read access to templates and generated contracts
  • HR Specialist: Full management of templates, snippets, attachments
  • HR Admin: Contract generation and signing management
  • Signer: Read‑only access for signing process

📦 Installation Steps

1️⃣ Download or clone into your addons folder:
odoo/addons/hr_contract_document/

2️⃣ Activate Developer Mode in Odoo → Update App List.
3️⃣ Search for “HR Contract Document Management” and click Install.

4️⃣ After installation, access via menu:
Human Resources → Contract Documents

⚙️ Extensibility

  • Custom placeholders and data render logic (extend Python model)
  • Additional QWeb or PDF report layouts
  • Integration with Odoo Sign or external signature platforms
  • Fully translatable (multi‑language ready)
