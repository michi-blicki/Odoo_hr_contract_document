# hr_contract_document

Advanced Contract Document Management for Odoo 18 Community

This module extends `hr_contract` by providing a flexible, versioned, and multilingual contract document framework.

## Key Features
- Structured and versioned contract templates
- Dynamic placeholders (auto-resolved from Employee and Contract models)
- Mandatory and optional text sections
- Translated attachments
- Signer rules (e.g., HR Manager, Team Lead)
- PDF rendering and automatic archiving

## Compatibility
- Compatible with **Odoo 18 Community**
- Fully functional without Odoo Enterprise modules

## Future Enhancements
- Integration for e-signature (Odoo Sign, DocuSign, Adobe Sign)
